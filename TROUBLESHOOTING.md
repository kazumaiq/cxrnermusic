# РУКОВОДСТВО ПО УСТРАНЕНИЮ НЕПОЛАДОК (TROUBLESHOOTING)
**CXRNER LINK · Решение частых проблем и диагностика**

---

## 1. Проблемы с доменом и DNS

### Симптом: `link.cxrnermusic.com` возвращает `SSL Handshake Failed` или статус в Vercel `Invalid Configuration`
- **Причина**: DNS-записи ещё не распространились по миру (обычно занимает от 5 до 30 минут) или Cloudflare включил проксирование до подтверждения SSL в Vercel.
- **Решение**:
  1. В панели Cloudflare временно переключите статус CNAME-записи `link` с оранжевого облака на **серое облако (DNS Only)**.
  2. В Vercel Dashboard нажмите кнопку **Refresh** в разделе Domains.
  3. Как только Vercel выпустит сертификат (зелёный статус), облако Cloudflare можно при желании вернуть в режим Proxied (с SSL-режимом Full/Strict).

### Симптом: При открытии `link.cxrnermusic.com` открывается главная страница лейбла, а не релиз
- **Причина**: Запрос не прошёл через `proxy.ts` из-за нестандартного заголовка `Host`.
- **Решение**: Проверьте, что в Vercel домен добавлен точно как `link.cxrnermusic.com`. Проверьте логи Vercel Functions на наличие рерайта в `/link/[slug]`.

## 2. Автопоиск по UPC / EAN

### Симптом: Ошибка «Неверная контрольная сумма UPC/EAN»
- **Причина**: Пользователь опечатался при вводе 12-значного (UPC-A) или 13-значного (EAN-13) штрихкода. Последняя цифра является проверочной суммой по алгоритму Modulo-10.
- **Решение**:
  1. Перепроверьте штрихкод из личного кабинета дистрибьютора (Believe, ONErpm, Tunecore, DistroKid).
  2. Если штрихкод ещё не присвоен или релиз эксклюзивный, переключитесь на вкладку «Поиск по названию» или введите метаданные вручную в мастере создания.

### Симптом: UPC валиден, но релиз не найден ни в Apple, ни в Deezer
- **Причина**: Релиз ещё находится на стадии предзаказа/модерации у стриминговых площадок и ещё не проиндексирован в публичном API Apple/Deezer.
- **Решение**:
  1. Нажмите «Заполнить вручную».
  2. Введите название трека, имя артиста и дату релиза.
  3. Загрузите обложку с компьютера.
  4. Ссылки на стриминги можно добавить позже в любое время в редакторе релиза `/dashboard/links/[id]/edit`.

## 3. Ошибки Supabase и RLS

### Симптом: Ошибка `new row violates row-level security policy for table "smart_links"`
- **Причина**: Пользователь не авторизован или в миграции не применилась политика для `authenticated`.
- **Решение**:
  1. Проверьте статус сессии: пользователь должен войти через `/auth/login`.
  2. Убедитесь, что миграция `supabase/migrations/003_cxrner_link_platform.sql` была выполнена полностью.
  3. Проверьте в Supabase Dashboard -> **Authentication** -> **Policies**, что для таблицы `smart_links` включены политики:
     - `smart_links_select_public`
     - `smart_links_insert_own`
     - `smart_links_update_own`
     - `smart_links_delete_own`

### Симптом: Ошибка при загрузке обложки в хранилище (`Bucket not found` или `Unauthorized`)
- **Причина**: Бакет `smart-links` не был создан или помечен как приватный.
- **Решение**:
  1. Откройте Supabase Dashboard -> **Storage**.
  2. Проверьте наличие бакета `smart-links`.
  3. Убедитесь, что бакет имеет статус **Public**.
  4. Примените блок политик для Storage из `supabase/migrations/003_cxrner_link_platform.sql`.

## 4. Ошибки загрузки картинок (Next.js Image)

### Симптом: В консоли браузера ошибка `Invalid src prop on `next/image`, hostname "..." is not configured under images in your `next.config.js``
- **Решение**:
  В `next.config.mjs` уже добавлены все популярные CDN музыкальных стримингов (`is1-ssl.mzstatic.com`, `i.scdn.co`, `e-cdns-images.dzcdn.net`, `avatars.yandex.net`, `*.supabase.co`).
  Если вы используете нестандартный хостинг картинок, добавьте его шаблон в `next.config.mjs` в массив `images.remotePatterns`.

## 5. Pre-save рассылка

### Симптом: Фанаты не получают уведомление в Telegram при наступлении даты
- **Причина**:
  1. Пользователь не нажал `/start` в боте лейбла (Telegram запрещает ботам писать первым пользователям, которые никогда не отправляли боту сообщений).
  2. Не задан `TELEGRAM_BOT_TOKEN` в переменных окружения.
- **Решение**:
  На странице смарт-ссылки при выборе Telegram Pre-save пользователю показывается ссылка на открытие диалога с ботом для инициализации связи.
